# 외대 제휴맵

한국외국어대학교 서울캠퍼스(이문동·회기 일대) 주변의 **학과 제휴 업체**와 **대학생 할인 매장**을 한 지도에서 보는 인터랙티브 웹페이지입니다.
OpenStreetMap 지도를 쓰기 때문에 API 키 없이 바로 동작합니다.

## 실행

빌드가 필요 없는 정적 페이지입니다.

- 로컬: `index.html`을 브라우저로 열기 (또는 `python3 -m http.server` 후 http://localhost:8000)
- 배포: GitHub 저장소 **Settings → Pages → Branch** 에서 이 브랜치를 선택하면 `https://<아이디>.github.io/map/` 으로 공개됩니다.
  (‘내 위치’ 기능은 https 또는 localhost에서만 작동합니다.)

## 기능

| 기능 | 설명 |
| --- | --- |
| 지도 | 외대 서울캠퍼스 중심, 외대앞·회기·신이문역 표시, 도보 5/10/15분 반경 |
| 핀 | 업종별 색상·아이콘. 주황 테두리 = 학과 제휴 포함(숫자는 제휴 개수), 분홍 테두리 + ‘내’ = 내 학과 제휴 |
| 내 학과 | 학과를 고르면 해당 학과 제휴(및 총학생회 제휴)가 강조되고 목록 맨 위로 올라옴 |
| 필터 | 전체 / 학과 제휴 / 대학생 할인 / 즐겨찾기, 업종 칩, 검색(업체명·혜택·학과), 지난 혜택 숨기기 |
| 정렬 | 캠퍼스에서 가까운 순 · 혜택 많은 순 · 이름순 (도보 시간 자동 계산) |
| 연동 | 목록에 마우스를 올리면 핀 강조, 핀/목록 클릭 시 지도 이동 + 상세 카드 |
| 상세 | 혜택별 대상 학과·기간(D-30 이내 마감 임박 표시), 이용 조건, 카카오맵 길찾기·네이버지도 링크 |
| 공유 | 업체를 열면 주소가 `#p03` 형태로 바뀜 → 그 링크를 보내면 해당 업체가 바로 열림 |
| 업체 추가 | [+ 업체 추가] → 지도 클릭 → 정보 입력. 브라우저에 저장되며 수정·삭제 가능 |
| 데이터 관리 | 추가한 업체를 포함한 전체 데이터를 `places.js`로 내려받기 / JSON 복사 / JSON 가져오기 |
| 모바일 | 지도 위 바텀시트(손잡이를 위아래로 끌어 펼치기·접기), 다크 모드 자동 대응 |

## 실제 제휴 정보로 바꾸기

**`data/places.js` 한 파일만 고치면 됩니다.** 지금 들어 있는 18곳은 화면 구성을 보여주기 위한 **예시 데이터**(가상의 업체)입니다.

가장 쉬운 방법:
1. 지도에서 [+ 업체 추가]로 실제 업체들을 등록
2. 오른쪽 위 내려받기 버튼 → **places.js 내려받기**
3. 받은 파일에서 `sample: true`인 예시 항목을 지우고 `data/places.js`를 교체 후 커밋

직접 편집할 때 형식:

```js
{
  id: "p01",                 // 고유 값 (공유 링크 #p01 에 쓰임)
  name: "업체명",
  category: "food",          // food 식당 · cafe 카페 · pub 주점 · life 생활·건강 · fun 문화·여가 · study 학습·인쇄
  lat: 37.5958, lng: 127.0622,
  address: "이문로 ○○",
  hours: "11:00 – 21:00",
  conditions: "학생증 제시",
  benefits: [
    { kind: "dept", departments: ["경영학부"], text: "전 메뉴 10% 할인", until: "2026-12-31" }, // 학과 제휴
    { kind: "dept", departments: ["전체 재학생"], text: "총학생회 제휴 ..." },                  // 모든 학과 대상
    { kind: "student", text: "학생증 제시 시 음료 무료" }                                     // 대학생 할인
  ]
}
```

- `until`(종료일)은 생략하면 상시 혜택. 지난 혜택은 기본으로 숨겨집니다.
- 학과 목록, 캠퍼스 좌표, 표시할 역은 같은 파일의 `MAP_CONFIG`에서 바꿀 수 있습니다.
- 좌표는 카카오맵/네이버지도에서 장소를 우클릭해 복사하거나, 지도에서 업체 추가 시 자동으로 들어갑니다.

## 파일 구성

```
index.html        페이지 뼈대
css/style.css     디자인 (라이트/다크)
js/app.js         지도·필터·목록·추가 기능
data/places.js    캠퍼스 설정 + 업체 데이터  ← 여기만 고치면 됨
```
