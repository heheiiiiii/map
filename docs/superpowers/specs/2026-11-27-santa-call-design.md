# 산타 영상통화 (santa-call) 설계

작성일: 2026-11-27

## 1. 의도

산타 할아버지와 1:1로 **음성 대화**하는 영상통화 웹사이트. 사용자가 **혼자 재미로** 쓰는 개인 프로젝트다.
게임풍 "애니멀리즈(Animalese)" 합성음과 한 글자씩 찍히는 말풍선으로, 아늑한 동물 마을 게임 같은 통화 경험을 만든다.

흐름: 통화 걸기 → 산타가 먼저 인사 → 내가 말함 → 음성 인식 → Claude가 산타답게 답변 + 표정 선택 → 애니멀리즈 음성과 말풍선으로 들려줌 → 다시 내 차례.

## 2. 목표 / 비목표 / 안티목표

**목표**
- 버튼 누를 필요 없이 그냥 말하면 대화가 이어지는 자연스러운 턴 교대
- 말풍선 타이핑과 애니멀리즈 소리가 정확히 동기화되는 "그 느낌"
- 대화 내용에 맞춰 바뀌는 산타 표정 (5종)
- `npm install && npm start` 한 번으로 로컬 실행

**비목표 (1차 범위 밖)**
- 배포, 로그인, 여러 사용자
- 크롬 외 브라우저 지원 (안내 문구만 표시)
- 탭을 닫아도 남는 장기 기억
- 산타가 말하는 중에 끼어들기(barge-in)
- 내 웹캠 영상 표시
- 모바일 최적화 (깨지지 않는 정도만)

**안티목표 (돌아가도 이러면 실패)**
- 답변이 길고 설교조라 통화 느낌이 안 남
- 산타 목소리를 마이크가 다시 인식해 혼자 대화가 무한 반복됨
- 응답 대기 중 화면이 멈춘 듯 아무 반응이 없음
- 기존 게임 캐릭터나 아트를 재현함 (산타와 배경은 전부 오리지널 SVG)

## 3. 제약

- **브라우저:** 크롬. 음성 인식은 크롬의 `webkitSpeechRecognition`(ko-KR)에 의존한다.
- **API 키:** Anthropic API 키는 서버의 `.env`에만 둔다. 브라우저 코드에 절대 넣지 않는다.
- **오디오 재생 정책:** 브라우저는 사용자의 클릭이 있어야 오디오를 켤 수 있다. "통화 걸기" 클릭 시점에 `AudioContext` 생성과 마이크 권한 요청을 함께 한다.
- **위치:** 기존 지도 프로젝트와 분리해 저장소 안의 `santa-call/` 폴더에 둔다.

## 4. 접근법 (사용자 선택: A)

| 안 | 구성 | 장단점 |
|---|---|---|
| **A (선택)** | 순수 HTML/CSS/JS + 작은 Node(Express) 서버. 음성 인식은 Web Speech API, 애니멀리즈는 Web Audio로 직접 합성 | 가장 단순하고 무료 STT. 대신 크롬 전용 |
| B | A + 서버측 STT(Whisper 등) | 브라우저 무관, 정확도 약간↑. 대신 키·비용 추가, 업로드 지연 0.5~1초 |
| C | React/Vite | 화면 하나짜리엔 빌드 도구만 늘어나는 과한 선택 |

선택 이유: 혼자 크롬으로 쓰니 B의 장점이 불필요하고, A가 가장 빨리 즐길 수 있다. A에서 B로 전환도 STT 모듈 교체로 가능하다.

## 5. 설계

### 5.1 파일 구조

```
santa-call/
  package.json          # express, @anthropic-ai/sdk, dotenv
  .env.example          # ANTHROPIC_API_KEY=
  server.js             # 정적 파일 서빙 + POST /api/chat
  character.js          # 산타 설정: 이름, 성격 프롬프트, 목소리 파라미터, 표정 목록, 첫 인사
  public/
    index.html
    css/style.css
    js/app.js           # 통화 상태 머신, 화면 전환
    js/stt.js           # Web Speech API 래퍼
    js/animalese.js     # 한글 분해 + Web Audio 합성 + 재생 스케줄
    js/dialogue.js      # 말풍선 타이핑, 페이지 넘김, 소리 동기화
    js/santa.js         # 산타 SVG와 표정 및 입 모양 제어
  test/                 # node:test 단위 테스트
```

캐릭터 관련 값은 `character.js` 한 곳에 모은다. 서버는 성격 프롬프트를, 브라우저는 목소리와 표정 값을 `/api/character`로 받아 쓴다.

### 5.2 통화 상태 머신 (app.js)

```
start ──클릭──▶ ringing(1.5초, 연결음) ──▶ greeting(산타 첫 인사)
   ▲                                          │
   └──── ended ◀──종료 버튼── listening ◀──────┘
                               │   ▲
                       최종 인식문 │   │ 말하기 끝 + 0.8초
                               ▼   │
                            thinking ──응답──▶ speaking
```

- **listening:** 마이크 ON. 인식 중인 내 말을 화면 아래 자막으로 실시간 표시한다.
- **thinking:** 마이크 OFF. 산타는 "생각 중" 표정(수염 만지기)을 짓고 점 세 개 애니메이션을 보여준다.
- **speaking:** 마이크 OFF. 말풍선 타이핑과 애니멀리즈를 재생한다. 끝나면 listening으로 돌아간다. 마이크가 산타 목소리를 다시 인식하는 문제는 이 상태에서 마이크를 끄는 것으로 막는다.
- **음소거 버튼:** listening 상태에서 마이크를 수동으로 끄고 켠다.
- **종료 버튼:** 인식을 중단하고 소리를 멈춘 뒤 "통화 종료 · 03:21" 화면을 보여주고, 다시 걸기 버튼을 둔다.
- **통화 시간:** greeting부터 상단 타이머가 흐른다.

### 5.3 음성 인식 (stt.js)

- `lang='ko-KR'`, `interimResults=true`, `continuous=false`로 설정한다. 사용자가 말을 멈추면 브라우저가 알아서 한 턴을 끝낸다.
- 최종 결과가 비어 있거나 `no-speech` 오류가 나면 조용히 다시 듣기 시작한다.
- `not-allowed` 오류가 나면 마이크 권한 안내 화면을 보여준다.
- `webkitSpeechRecognition`이 없는 브라우저에서는 시작 화면에 "크롬에서 열어주세요"를 표시한다.

### 5.4 답변 생성 (server.js)

- `POST /api/chat`의 요청 본문은 `{ messages: [{role, content}] }`이다. 대화 기록은 브라우저 메모리에 두고, 매 요청마다 최근 20턴까지 보낸다.
- 공식 SDK `@anthropic-ai/sdk`로 Claude를 호출한다. 호출 설정은 다음과 같다.
  - 모델 `claude-opus-5-5`, `output_config.effort: "low"` (잡담이라 낮은 effort로 지연을 줄임)
  - 구조화 출력(`output_config.format`) 스키마: `{ reply: string, expression: "neutral"|"happy"|"thinking"|"surprised"|"sad" }`
  - 거절 대비 서버측 fallback(`fallbacks: "default"`)을 켜고, `stop_reason`을 확인한다
- 성격 프롬프트(character.js)에는 다음 내용을 담는다.
  - 북극 작업실에서 영상통화를 받는 다정한 산타 할아버지
  - 반말로 "허허", "호호호"
  - 1~3문장, 한국어
  - 소원·올해 이야기·고민을 들어주고, 가끔 루돌프와 요정 얘기를 꺼냄
  - 이모지와 마크다운 금지 (말풍선과 합성음에 그대로 들어가므로)
- 실패(네트워크, 429, 5xx)하면 브라우저가 미리 정해둔 대사를 대신 재생한다. 예: "어이쿠, 썰매 신호가 약하구나… 다시 한 번 말해주겠니?" 표정은 surprised로 한다.

### 5.5 애니멀리즈 합성 (animalese.js)

1. **한글 분해:** 음절을 `(code - 0xAC00)`로 계산해 초성·중성·종성으로 나눈다. 영문과 숫자는 근사 모음으로 매핑한다.
2. **음절당 소리 하나:** Web Audio로 짧은 블립을 만든다.
   - 초성이 있으면 10~20ms짜리 짧은 노이즈 또는 클릭으로 자음 느낌을 낸다.
   - 이어서 중성 모음의 포먼트(F1/F2 밴드패스 두 개)를 통과한 톱니파를 낸다.
   - 길이는 약 85ms(산타용으로 느리게), 빠른 attack과 decay 엔벨로프를 쓴다.
3. **음높이:** 기본 음높이(산타는 낮게, 예: 150Hz)에 음절마다 ±12% 랜덤 흔들림을 준다. 문장 끝 `?`는 상승, `!`는 위로 튀게 한다. "호호호"나 "허허"는 리듬감 있게 음높이를 계단식으로 떨어뜨린다.
4. **쉼:** 띄어쓰기는 40ms, `, …`는 200ms, `. ! ?`는 350ms를 쉰다.
5. **공개 API:** `speak(text, voice)`는 글자별 재생 시각 스케줄 `[{char, t}]`를 반환하고 재생을 시작한다. 각 수치는 `character.js`의 voice 값으로 조절한다.

### 5.6 말풍선 (dialogue.js)

- 화면 아래쪽에 둥근 크림색 말풍선을 둔다. 산타 이름표를 붙이고 오리지널 디자인으로 만든다.
- 애니멀리즈 스케줄에 맞춰 글자를 한 자씩 표시한다. 산타 입은 음절마다 열렸다 닫힌다.
- 답변을 문장 단위로 나눠 최대 2줄씩 한 페이지로 보여준다. 페이지가 끝나면 ▼ 표시 후 0.9초 뒤에 자동으로 넘긴다.
- 말풍선을 클릭하거나 스페이스를 누르면 현재 페이지가 즉시 전부 표시된다.

### 5.7 산타와 배경 (santa.js, 오리지널 SVG)

- **표정:** neutral(기본, 가끔 눈 깜빡임), happy(눈 감고 웃음), thinking(눈 위로, 수염 만지는 손), surprised(동그란 눈), sad(처진 눈썹). 입은 말할 때 열림과 닫힘을 토글한다.
- **배경:** 벽난로(불꽃 애니메이션), 선물 더미, 창밖에 내리는 눈(CSS 파티클), 따뜻한 조명. 산타는 책상 뒤에 앉아 있다.

### 5.8 화면 구성

```
┌──────────────────────────────────────┐
│ ● 산타 할아버지        🔒 02:14       │  ← 상단 바 (이름, 통화시간)
│                                      │
│        [작업실 배경 + 산타 SVG]        │
│                              ┌─────┐ │
│                              │ 나  │ │  ← 내 PiP: 아바타 + 마이크 음량 링
│ ┌──────────────────────────┐ └─────┘ │
│ │산타│ 허허, 그랬구나~        │         │  ← 말풍선
│ │    올해 정말 애썼구나! ▼    │         │
│ └──────────────────────────┘         │
│      "오늘 회사에서 칭찬받았어요"        │  ← 내 말 실시간 자막
│          [🎤 음소거]  [📞 종료]          │
└──────────────────────────────────────┘
```

시작 화면에는 산타 썸네일, "산타 할아버지" 이름, 초록색 "영상통화 걸기" 버튼을 둔다.

## 6. 실행 방법

```
cd santa-call
npm install
cp .env.example .env   # ANTHROPIC_API_KEY 입력
npm start              # http://localhost:3000 을 크롬으로 열기
```

- **단위 테스트(node:test):**
  - 한글 분해

  - `/api/chat`: SDK 모킹으로 구조화 출력 파싱과 실패 시 응답
- **수동 체크리스트:**
  - 마이크 권한 허용과 거부
  - 침묵 시 재시작
  - 산타 말하는 중 마이크 꺼짐
  - 종료 후 재통화
  - API 키가 없을 때 안내

## 8. 빌더 재량 / 확인된 결정

**확인된 결정(사용자):** 산타 캐릭터, 개인용·로컬 실행, 접근법 A.

**설계자 판단(사용자가 바꿀 수 있음):**
- 산타가 먼저 인사한다 (고정 인사 1개, API 호출 없음)
- 말하면 자동 인식하고, 산타가 말하는 동안 마이크를 끈다
- 답변은 1~3문장이고, 표정은 AI가 5종 중 선택한다
- 내 웹캠 대신 아바타와 마이크 음량 링을 표시한다
- 모델은 `claude-opus-5-5`, effort는 low

**빌더 재량:** SVG 세부 아트, 포먼트와 음높이 수치 튜닝, CSS 세부, 연결음 사운드(Web Audio로 합성).
