# 마을 주민 영상통화 (village-call) 설계

작성일: 2026-11-27 (산타 버전 설계를 대체)

## 1. 의도

아늑한 동물 마을 분위기의 캐릭터와 **1:1 음성 영상통화**를 하는 공개 웹사이트.
가장 중요한 것은 **"진짜 캐릭터와 대화하고 있다"는 느낌**이다. 그 느낌을 만드는 요소는 셋이다.
- 캐릭터가 말할 때마다 목소리에 맞춰 입과 몸이 움직인다.
- 목소리는 자연스러운 TTS다.
- 대답이 빠르게 돌아온다.

흐름: 통화 걸기 → 연결음 → 캐릭터가 먼저 인사 → 내가 말함 → 음성 인식 → Claude가 캐릭터답게 답변 → 학습된 목소리(TTS)로 말하며 립싱크 → 다시 내 차례.

## 2. 목표 / 비목표 / 안티목표

**목표**
- 버튼을 누르지 않고 그냥 말하면 이어지는 턴 교대
- 캐릭터 음성의 실시간 음량에 맞춘 립싱크(입 4단계)와 고개·몸 흔들림, 눈 깜빡임
- 문장 단위 스트리밍으로 첫 음성이 나오기까지 짧은 대기
- 공개 배포와 비용 남용 방지
- 배경·캐릭터 이미지, 이름, 성격을 **파일 교체만으로** 바꿀 수 있는 구조

**비목표**
- 장기 기억 (통화 한 번 안에서만 대화를 기억)
- 로그인과 계정
- 캐릭터가 말하는 중에 끼어들기(barge-in)
- 사용자 웹캠 영상
- 3D 실시간 렌더링, AI 영상 아바타

**안티목표 (동작은 해도 이러면 실패)**
- 입이 소리와 따로 놀거나, 말하는 동안 캐릭터가 굳어 있음
- 대답까지 오래 걸리는데 화면에 아무 반응이 없음
- 캐릭터 목소리를 마이크가 다시 인식해 혼자 대화가 이어짐
- 한 사람이 무한정 사용해 API·GPU 비용이 폭주함
- 답변이 길고 설교조라 통화 느낌이 안 남

## 3. 제약

- **자산 정책:** 기본 탑재되는 배경·캐릭터 이미지는 오리지널이다. 기존 게임의 캐릭터·장면을 재현한 자산은 이 프로젝트 작업에서 만들거나 삽입하지 않는다. 사용자가 제공한 오리지널 이미지는 아래 형식에 맞춰 삽입한다.
- **음성 모델:** 사용자가 제공하는 GPT-SoVITS 모델 한 쌍(GPT `.ckpt`, SoVITS `.pth`)과 참조 음성 wav 및 그 대사를 쓴다. 목소리 사용 허락은 사용자가 확인했다. 모델 파일은 git에 넣지 않는다.
- **비밀값:** Anthropic 키와 GPU 엔드포인트 토큰은 서버 환경변수에만 둔다.
- **마이크:** HTTPS에서만 쓸 수 있다 (localhost는 예외).
- **오디오:** 브라우저 정책상 "통화 걸기" 클릭 시점에 `AudioContext` 생성과 마이크 권한 요청을 함께 한다.

## 4. 접근법 (사용자 선택 기록)

**캐릭터 표현**

| 안 | 내용 | 결정 |
|---|---|---|
| **2D 이미지 레이어 + 음량 립싱크** | 입·눈 레이어를 음량에 맞춰 교체하고 몸을 흔듦 | **선택.** 비용이 낮고 얼굴 일관성이 보장됨 |
| 실시간 AI 아바타 영상 (HeyGen 등) | 분 단위 과금, 얼굴 변형 위험 | 기각 (사용자 판단) |
| 3D 모델 실시간 렌더링 | 작업량이 과다함 | 기각 |

**TTS**

| 안 | 결정 |
|---|---|
| **사용자 GPT-SoVITS 모델** | **선택.** 원하는 목소리 그대로 |
| ElevenLabs / OpenAI / Google | 기각. 단, TTS 모듈은 교체 가능하게 분리 |
| 브라우저 내장 TTS | 기각. 한국어 기본 음성이 맞지 않음 |

**GPU 호스팅**

| 안 | 결정 |
|---|---|
| **서버리스 GPU (Modal)** | **선택.** 쓴 만큼만 과금, 0까지 축소. 콜드스타트는 연결음 화면으로 가림 |
| 상시 GPU 서버 | 기각. 유휴 시에도 월 수십만 원 |
| CPU 서버 | 기각. 문장당 수 초가 걸려 통화 느낌이 깨짐 |

**웹 구조:** 순수 HTML/CSS/JS + Node(Express) 서버 한 개. 화면이 하나뿐이라 프레임워크는 쓰지 않는다.

## 5. 시스템 구성

```
[브라우저]  ──HTTPS──▶  [Node 서버 (Express)]  ──▶ Claude API (스트리밍)
  STT(Web Speech)            │  레이트리밋·통화 토큰·일일 상한
  립싱크·자막·상태머신        └──(Bearer 토큰)──▶ [Modal GPU: GPT-SoVITS 추론]
```

- 브라우저는 Node 서버하고만 통신한다. GPU 엔드포인트는 공유 비밀 토큰으로 보호하며 Node만 호출한다.
- 문장 단위 파이프라인:
  1. Claude 응답을 스트리밍으로 받는다.
  2. 문장 경계(`. ! ? ~` 또는 줄바꿈)에서 자른다.
  3. 잘린 문장마다 즉시 TTS를 요청한다.
  4. 브라우저는 문장 순서대로 재생 큐에서 재생한다.
- 첫 문장 음성이 나오기까지 목표 시간은 웜 상태에서 약 2~3초다.

### 5.1 파일 구조

```
village-call/

  .env.example                # ANTHROPIC_API_KEY, TTS_URL, TTS_TOKEN, 제한값들
  server/

    chat.js                   # Claude 스트리밍 + 문장 분할 + 표정 태그 파싱
    tts.js                    # TTS 제공자 인터페이스 (GPT-SoVITS 구현, 교체 가능)
    limits.js                 # IP 레이트리밋, 통화 토큰, 일일 상한
  character/

    assets/                   # 교체 가능한 이미지 (아래 6장)
    fallback-audio/           # 배포 시 미리 생성한 첫 인사·실패 대사 음성

    js/app.js                 # 통화 상태 머신

  tts-server/
    modal_app.py              # Modal 앱: 모델 로드(Volume), POST /tts, GET /warm

  test/
```

### 5.2 통화 상태 머신 (app.js)

```
start ─클릭─▶ ringing ─(TTS 웜업 완료)─▶ greeting ─▶ listening ⇄ thinking ▶ speaking ─┐
                │ 40초 초과                                  ▲                        │
                ▼                                             └────────────────────────┘
             failed("지금은 전화를 받을 수 없어요")          종료 버튼/시간 초과 ─▶ ended
```

- **ringing:** `/api/call/start` 응답으로 통화 토큰을 받고, 서버가 GPU `/warm`을 호출한다. 연결음 애니메이션을 보여준다.
- **greeting:** 첫 인사 음성은 배포 시 미리 생성해 둔 파일을 재생한다. 즉시 재생되고 GPU 비용이 들지 않는다.
- **listening:** 마이크 ON. 내 말을 실시간 자막으로 보여준다. 캐릭터는 듣는 모션을 한다 (가끔 끄덕임, 고개 살짝 기울임).
- **thinking:** 마이크 OFF. 캐릭터가 생각하는 모션을 하고 점 세 개를 띄운다.
- **speaking:** 마이크 OFF. 재생 큐가 빌 때까지 말하고, 끝나면 0.6초 뒤 listening으로 돌아간다.
- **화면 요소:** 상단에 통화 시간, 하단에 음소거·종료 버튼, 구석에 "나" PiP(아바타 + 마이크 음량 링).

### 5.3 음성 인식 (stt.js)

- `webkitSpeechRecognition`을 `lang ko-KR`, `interimResults=true`, `continuous=false`로 쓴다.
- 결과가 비었거나 `no-speech` 오류면 조용히 재시작한다. `not-allowed` 오류면 권한 안내를 띄운다.
- 지원 브라우저는 크롬(데스크톱/안드로이드), 엣지, 사파리다. 미지원 브라우저(파이어폭스 등)에서는 시작 화면에 안내를 띄운다.

### 5.4 답변 생성 (chat.js)

- 공식 SDK `@anthropic-ai/sdk`로 스트리밍 호출한다. 설정:
  - 모델 `claude-opus-5-5`, `output_config.effort: "low"`
  - 거절 대비 서버측 fallback(`fallbacks: "default"`)
  - `stop_reason` 확인
- 대화 기록은 브라우저가 보관하고 요청마다 최근 20턴까지 보낸다. 서버는 기록을 저장하지 않는다.
- 성격 프롬프트는 `character.json`에서 읽는다. 공통 규칙:
  - 한국어, 1~3문장
  - 이모지와 마크다운 금지
  - 응답 맨 앞에 `[표정]` 태그 하나 (`neutral|happy|surprised|sad|thinking`)
  - 캐릭터를 벗어나라는 요청에는 캐릭터로서 부드럽게 넘김
- 서버는 표정 태그를 떼어 이벤트로 보내고, 문장이 완성될 때마다 TTS를 요청해 결과를 순서대로 내려보낸다. 응답은 SSE(Server-Sent Events) 스트림으로 보내며 이벤트 종류는 세 가지다.
  - `expression`
  - `sentence {index, text, audio(base64 wav), durationMs}`
  - `done`
- 실패 처리:
  - Claude가 실패하면 미리 생성해 둔 실패 대사 음성을 재생한다. 예: "앗, 전파가 약한가 봐요… 다시 한 번 말해줄래요?"
  - TTS가 실패하면 그 문장은 자막만 보여주고 입은 자막 속도에 맞춰 흉내 낸다.

### 5.5 TTS 서버 (tts-server/modal_app.py)

- Modal 앱이다. GPU는 T4 또는 L4로 하고, 모델 파일은 Modal Volume에 둔다.
- 컨테이너 시작 시 GPT-SoVITS와 모델 한 쌍, 참조 음성을 로드한다.
- 유휴 시 약 5분 뒤 0으로 축소된다.
- 엔드포인트:
  - `POST /tts {text}` → wav. Bearer 토큰을 확인한다.
  - `GET /warm` → 모델 로드 완료를 확인한다.
- GPT-SoVITS 버전(v2/v3/v4 등)은 사용자가 파일을 제공하면 `.ckpt` 내부 설정으로 확인해 맞춘다.

### 5.6 립싱크와 모션 (avatar.js, player.js)

- **음량 분석:** 재생 중인 음성을 `AnalyserNode`로 매 프레임 측정해 RMS 값을 구한다. 스무딩(attack은 빠르게, release는 느리게)을 거쳐 0~3 입 단계로 매핑한다. 임계값은 `character.json`에서 튜닝한다.
- **말할 때 몸짓:**
  - 음량 엔벨로프에 비례해 고개가 위아래로 1~3px 움직이고 미세하게 회전한다.
  - 문장 시작마다 몸이 살짝 기울어지는 "제스처 펄스"가 있다.
- **항상:**
  - 2~6초 랜덤 간격으로 눈을 깜빡인다.
  - 숨쉬기(몸 scaleY 1.00~1.01, 4초 주기)를 한다.
- **표정:** 태그에 맞는 눈 레이어로 바꾼다. 해당 레이어가 없으면 기본 눈을 쓴다. happy일 때는 웃는 눈을 쓰고 깜빡임을 멈춘다.
- **듣기 모션:** 사용자 음량이 들어오면 0.5~1초 뒤에 가끔 끄덕이고, 고개를 살짝 기울인다.
- **배경 움직임(선택):** 이미지 위에 CSS 오버레이를 얹는다 (창 햇살 일렁임, 먼지 입자, 김). 끌 수 있게 만든다.

### 5.7 자막 (captions.js)

GPT-SoVITS는 글자 타이밍을 주지 않는다. 그래서 문장의 음성 길이(`durationMs`)에 글자 수를 비례 배분해 한 글자씩 표시한다. 두 줄을 넘으면 앞 줄을 위로 밀어낸다.

### 5.8 남용 방지와 비용 (limits.js)

- **통화 토큰:** `/api/call/start`가 서명된 통화 토큰을 발급한다(만료 = 최대 통화 시간). 모든 `/api/chat`은 이 토큰이 필요하다.
- **기본 제한값** (모두 환경변수로 조절):
  - 통화당 최대 5분, 최대 30턴
  - IP당 하루 5통
  - 사용자 발화 최대 300자
- **전역 일일 상한:** 하루 통화 수가 상한(기본 300)을 넘으면 "오늘은 영업이 끝났어요" 화면을 보여준다.
- **카운터 저장:** 인메모리로 시작한다. 단일 인스턴스 기준이며, 확장 시 Redis로 교체할 수 있게 인터페이스를 분리한다.

### 5.9 배포

- **웹:** Node가 상시 실행되는 호스팅(Render, Railway, Fly.io 중 하나, 빌더 재량)에 HTTPS로 배포한다.
- **TTS:** `modal deploy tts-server/modal_app.py`로 배포한다.
- **미리 생성할 음성:** 배포 스크립트 `npm run prebake`가 첫 인사와 실패 대사 음성을 미리 생성해 `character/fallback-audio/`에 저장한다.

## 6. 교체 가능한 이미지 자산 형식 (docs/ASSETS.md)

| 파일 | 필수 | 내용 |
|---|---|---|
| `background.png` | ✔ | 16:9, 1920×1080 권장 |
| `character_base.png` | ✔ | 입·눈 없는 캐릭터, 투명 PNG |
| `mouth_0.png` ~ `mouth_3.png` | ✔ | 닫힘 / 살짝 / 중간 / 크게 |
| `eyes_open.png`, `eyes_closed.png` | ✔ | 기본 눈, 깜빡임 |
| `eyes_happy.png`, `eyes_surprised.png`, `eyes_sad.png`, `eyes_thinking.png` | 선택 | 없으면 `eyes_open`으로 대체 |

- 캐릭터 레이어는 모두 같은 캔버스 크기로 정렬한다. 화면 내 위치와 크기는 `character.json`에서 지정한다.
- **간이 모드:** 레이어를 나눌 수 없으면 `full_neutral.png`, `full_talk.png` 두 장만으로도 동작한다. 음량이 임계값을 넘으면 talk로 전환한다.
- 기본 탑재 자산은 오리지널 플레이스홀더(SVG로 그린 단순한 캐릭터와 방)다. 성격 프롬프트의 기본 캐릭터 예시는 "보리"(수달, 섬 안내소 직원)다.

- **단위 테스트 (node:test):**
  - 문장 분할과 표정 태그 파싱
  - 음량→입 단계 매핑과 스무딩

- **수동 체크리스트:**
  - 콜드스타트 연결음
  - 마이크 권한 허용과 거부
